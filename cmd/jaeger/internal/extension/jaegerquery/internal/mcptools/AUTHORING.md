# Writing a skill

The guide to writing a skill lives on the website, in
[Custom Skills](https://www.jaegertracing.io/docs/latest/ai/skills/): when a
skill is the right answer, the index line that gets it read, the anatomy of a
skill file, how to write a procedure that decides, and how to test it against a
real trace.

A built-in skill in the `skills/` directory beside this file follows the same
guide. The only difference is the link path: a built-in skill is linked from the
root `SKILL.md` without the `custom/` prefix, for example
`detect-n-plus-one/SKILL.md`.
